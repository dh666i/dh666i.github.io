Vision

让评委先失语，再开始看细节。

我把页面设计成一个有层次的舞台：远景是生成式流场，中景是玻璃和扫描线，近景是跟手的交互反馈。视觉不只是装饰，而是每一次滚动、悬停、点击都会发生的响应。

01

First Impact

超大字重、霓虹梯度、实时画布，把第一屏做成能截图传播的视觉锤。

02

Responsive Physics

指针不是鼠标，是力场。按钮、卡片、粒子都会对它做出不同层级的反应。

03

Scroll Direction

滚动改变导航、进度条、文字入场和视觉密度，让页面有镜头语言。

Craft

顶级 Web 炫技，不靠堆素材。

全部在静态页面内完成。没有构建步骤，没有后端，只有 HTML、CSS、JavaScript 和对浏览器渲染能力的压榨。

A

Generative Field

Canvas 粒子流场根据指针和滚动速度实时重绘，首屏天然动态。

B

Kinetic Typography

超大标题、混合模式、文字阴影和分段揭示，制造竞赛级视觉记忆点。

C

Interaction Layer

磁吸按钮、3D 倾斜、聚光灯卡片和可切换能量模式，让页面不是静止海报。

D

Deployable Art

GitHub Pages 直接托管，移动端降级合理，减少炫技和访问稳定性的冲突。

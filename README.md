# CHICHI｜网页造境实验室

一个中文主导的个人视觉站。当前版本从“堆特效”转向更克制的网页造境：

- 中文排版作为主视觉
- 纸感、墨色、朱砂色的视觉系统
- 轻量 Canvas 流场背景
- 滚动显影、进度线、磁吸反馈
- 微幅 3D 卡片倾斜和聚光细节
- 移动端防溢出和动效降级

## 本地预览

```powershell
python -m http.server 4173
```

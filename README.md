# CHICHI Web Visual Lab

一个为视觉竞赛方向升级的零依赖静态网站。当前版本聚焦：

- 生成式 Canvas 粒子流场
- 磁吸指针与自定义光标
- 滚动进度与滚动叙事
- 3D 倾斜卡片与聚光灯 hover
- 玻璃 HUD、扫描线、噪声纹理和霓虹视觉系统
- GitHub Pages 直接部署，无需构建步骤

## 本地预览

```powershell
python -m http.server 4173
```

访问：

```text
http://localhost:4173
```

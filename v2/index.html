04 · 答GOOD TO KNOW

关于迟迟，四问。

这是迟迟的个人产品与开源项目空间。这里收录我日常开发的 AI 工具、媒体应用与桌面小工具，迟迟 API 是其中首个对外提供的核心服务。

官网目前涵盖 GPT、Claude、Gemini 与 Grok 等主流系列模型，采用标准 OpenAI 兼容格式接入。具体可用型号与最新上线列表，请以 chichiapi.cn ↗ 实时展示为准。

请直接前往 迟迟 API 官网 ↗ 查看当前各模型的费率、额度规则与使用说明，按实际使用需求选择即可。

API 配置问题可先查阅 迟迟 API 使用教程 ↗；公开项目的功能建议或 Bug 可直接在对应 GitHub 仓库提交 Issue，或通过下方联系方式直接找到我。
